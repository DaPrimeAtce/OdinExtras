# OdinExtras

An Odin addon module that adds various random features for use in Hypixel Skyblock.
Created using the [OdinAddon](https://github.com/odtheking/OdinAddon) template.

(This mod is not affiliated with odtheking or the Odin dev team, it is an unofficial addon mod)

A list of features that OdinExtras adds can be found [here](https://github.com/DaPrimeAtce/OdinExtras/blob/26.1/FEATURES.md)
