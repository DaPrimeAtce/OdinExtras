# OdinExtras Feature List
## Dungeon:
- Teammate Deaths: Customizable on player death message, and alert features for when a specified threshold of deaths in a dungeon run has been reached.
- Teammate Nametags: Brings back OdinLegacy's Teammate Nametags, with an option to scale the nametag to your liking.
- Customizable Leap Message (added into base Leap Menu module)
- 300 Score Message & Custom Title + 270 Score Features (added into base Map Info module)
## Boss:
- Professor, Storm Move, Storm Enrage, and Dragon Rag Tick Timers (added into base Tick Timers module)
## Render:
- CPS Display: Brings back OdinLegacy's CPS Display, with the addition of customizable spacing between the counter and the button name.
- Dropped Item Scale: Visually scales the size of items dropped on the ground. 
- Reindrake Health Display: Adds a health number display on Reindrakes.
- Slayer Display: Renders a HUD with the basic info of the current slayer you are fighting.
- Voidgloom Lasers: Renders a timer for when the laser phase of Voidgloom Seraph will end.
- Click GUI Scale & Alphabetical Sorting (added into base Click GUI module)
## Skyblock:
- Arrow Poison Display: Renders a HUD of how much Arrow Poision is in your inventory.
- Chat Commands+: Replaces base Chat Commands with more a customizable set of Chat Commands & adds some new commands as well.
- Chat Logger: Format and logs Party/Guild/Co-op/DM/Party Finder Join messages to the player's specified webhook ***(Webhook WILL reset if the config is used by not the same player.)***
- Server Alert: Sends a warning if you rejoin a server you were previously in. 
- Total Time, Time Lost to Lag, and Storm DPS Splits timers (added into base Splits module)
## Nether:
- Kuudra Eaten Timer: Renders a timer for how long until the player is eaten by kuudra.
